
# AI Studio Task Manager

A simple command-line task manager built using Python.

## Features
- Add tasks
- View all tasks
- Delete tasks
- Exit the application

## Requirements
- Python 3.11+
- uv

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd ai-studio-task-manager
```

Install dependencies:

```bash
uv sync
```

## Run the application

```bash
uv run python -m ai_studio_task_manager
```
